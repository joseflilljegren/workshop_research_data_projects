# Homework

To get familiar with claude and git your task is to:

1. Find any smallish project on GitHub (you can use GPT to find you one)
2. Use the terminal to navigate on your machine and to clone the repo to a local directory
3. `cd` into the cloned directory
4. Envoke `claude` and use claude to ask some questions about the code you just downloaded, such as: "What is this repo, and how could I use it?", "What are the package and environment requirements to run this code"
