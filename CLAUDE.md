# Data project workshop

This repo contains example code and workshop material for a workshop in Claude-driven data-projects in academia.

The workshop outlines techniques like:
 - git
 - package management
 - virtual environments
 - data storage
 - markdown
 - good pracitice in coding projects

## File structure:
- `data/`: Datasets used in the workshop
- `notes/`: Workshop notes (.md)
- `output/`: Any generated output
- `source_material/`: Raw source material for data capture
- `src/`: Reusable python code
- `.gitignore`: Pedagogically commented .gitignore-file
- `.env`: Pedagogically commented Environment variables
- `README.md`: Readme
- `CLAUDE.md`: This file
